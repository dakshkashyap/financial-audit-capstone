## Pipeline change worth testing next

1. Use deterministic tools for reconciliation, signs, period/unit checks and
   row localization. These tools establish only the assertions they test.
2. Let a cheap model identify the accounting issue and missing factual conditions
   from observable evidence. It must never receive the injected rule ID or gold
   error type/row as input.
3. Retrieve a small set of paragraph candidates and dated applicability metadata
   from an authorized source. Rank the candidates using the issue, evidence and
   exceptions; taxonomy membership alone is insufficient. Audit the exact top-k
   candidates shown to the model, not the coverage of the entire graph.
4. Require the selector to link each applicability condition to observed facts,
   explicitly reject plausible competing presentation/subject paragraphs, and
   abstain when authority or facts are insufficient. Exact quotation matching
   establishes textual presence, not entailment or governing authority.
5. For incomplete cases, acquire evidence through typed tools with costs. Score
   supported decisions and sufficient proof sets, alongside wasted acquisitions.
   Treat the current 16-case acquisition fixture as a software test, not an
   independently validated benchmark.

This is a proposed experimental method; it has not produced a measured citation
gain in the current artifacts. Graphs, multiple agents, retrieval and fixed tool
budgets already appear in related work. Any novelty claim must concern the
specific controlled evaluation and verified evidence/applicability annotations.
